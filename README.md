# Global Payout (Airwallex demo)

Upload a contractor payment file. Each person is paid the amount on the file in their local currency. The app prices the available rails, keeps the cheapest, and submits one wallet-funded Airwallex batch.

No login. The app uses the Airwallex account that belongs to the API key.
